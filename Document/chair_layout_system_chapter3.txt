1) ภาพรวมระบบ
==================================================
ระบบจัดผังเก้าอี้ในโปรเจกต์นี้ถูกออกแบบให้รองรับการทำงาน 5 ส่วนหลัก ได้แก่

1. การกำหนดจำนวนเก้าอี้ตั้งต้นจากจำนวนแถวและคอลัมน์ตอนสร้างห้องเรียน
2. การสร้างพิกัดตำแหน่งเก้าอี้เริ่มต้นแบบตาราง
3. การปรับผังเก้าอี้อัตโนมัติด้วยรูปแบบสำเร็จรูป เช่น rows, grid, groups และ scattered
4. การลากย้ายเก้าอี้ด้วยเมาส์หรือหน้าจอสัมผัส พร้อมควบคุมไม่ให้ออกจากกรอบ
5. การบันทึกผัง, การจองที่นั่งของผู้เรียน, และการซิงก์ข้อมูลแบบ real-time

โครงสร้างจริงของระบบกระจายอยู่ในไฟล์สำคัญดังนี้

1. Client/src/components/CreateClassModal.jsx

4. Client/src/utils/ChairValidation.js
5. Client/src/utils/ContainerUtils.js
6. Client/src/pages/ClassroomPage.jsx
7. Server/models/Class.js

9. Server/socket/socketHandler.js

2) โครงสร้างข้อมูลที่เกี่ยวข้องกับผังเก้าอี้
==================================================
ในฐานข้อมูล MongoDB มีการเก็บข้อมูลผังเก้าอี้ไว้ในโมเดล Class โดยฟิลด์สำคัญมีดังนี้

1. rows
   ใช้เก็บจำนวนแถวตั้งต้นของห้อง

2. cols
   ใช้เก็บจำนวนคอลัมน์ตั้งต้นของห้อง

3. seatingPositions
   ใช้เก็บพิกัดเก้าอี้ทั้งหมดในรูปแบบ object เช่น
   {
     "seat-0": { "x": 25, "y": 25 },
     "seat-1": { "x": 135, "y": 25 }
   }

4. assignedUsers
   ใช้เก็บว่าผู้ใช้คนใดนั่งอยู่ที่เก้าอี้ตัวใด เช่น
   {
     "seat-3": {
       "userId": "688...",
       "userName": "Student A",
       "photoURL": "/uploads/profile.png"
     }
   }

5. chairGroups
   ใช้เก็บการเชื่อมเก้าอี้เป็นกลุ่ม เช่น
   [
     {
       "id": "group-1770000000000",
       "chairIds": ["seat-1", "seat-2", "seat-5"],
       "label": "G1",
       "color": "#4CAF50"
     }
   ]

6. studentScores
   ใช้เก็บคะแนนของนักเรียนแต่ละคน เพื่อนำไปแสดงรอบเก้าอี้ในภายหลัง

หมายเหตุสำคัญ
พิกัด x และ y ที่ระบบเก็บ เป็นพิกัดของ "มุมซ้ายบน" ของกล่องเก้าอี้ ไม่ใช่จุดศูนย์กลางของเก้าอี้

3) การคำนวณจำนวนเก้าอี้ตั้งต้น
==================================================
ตอนสร้างห้องเรียน ระบบให้ผู้ใช้กำหนดจำนวนแถว rows และจำนวนคอลัมน์ cols จากนั้นคำนวณจำนวนเก้าอี้รวมด้วยสูตร

N = rows x cols

โดยที่
N = จำนวนเก้าอี้ทั้งหมด
rows = จำนวนแถว
cols = จำนวนคอลัมน์

ตัวอย่าง
ถ้ากำหนด rows = 5 และ cols = 6
จะได้

N = 5 x 6 = 30 ตัว

ข้อสังเกตจากระบบจริง
ในหน้า CreateClassModal.jsx มีการจำกัดค่าของ rows และ cols ให้อยู่ในช่วง 0 ถึง 10 เพื่อควบคุมขนาดของห้องเรียนและภาระการแสดงผล

==================================================
4) การคำนวณตำแหน่งเก้าอี้เริ่มต้นแบบตาราง
==================================================
การจัดตำแหน่งเก้าอี้ตั้งต้นเกิดขึ้นใน CreateClassModal.jsx โดยใช้การวนลูปแบบแถวก่อนคอลัมน์ (row-major order)

ค่าคงที่ที่ใช้จริงคือ

CHAIR_SPACING = 110 พิกเซล
START_OFFSET = 25 พิกเซล

สูตรหาพิกัดของเก้าอี้ตัวที่ i มีได้ 2 วิธีในการอธิบาย

วิธีที่ 1: ใช้ row และ col โดยตรง
x(i,j) = START_OFFSET + j x CHAIR_SPACING
y(i,j) = START_OFFSET + i x CHAIR_SPACING

โดยที่
i = ดัชนีแถว เริ่มที่ 0
j = ดัชนีคอลัมน์ เริ่มที่ 0

วิธีที่ 2: ใช้ seatIndex
row = floor(seatIndex / cols)
col = seatIndex mod cols
x = 25 + (col x 110)
y = 25 + (row x 110)

ชื่อเก้าอี้จะถูกสร้างเป็น
seat-0, seat-1, seat-2, ... ตามลำดับการวนลูป

ตัวอย่าง
ถ้า rows = 3 และ cols = 4

seat-0  -> row=0, col=0 -> (25, 25)
seat-1  -> row=0, col=1 -> (135, 25)
seat-2  -> row=0, col=2 -> (245, 25)
seat-3  -> row=0, col=3 -> (355, 25)
seat-4  -> row=1, col=0 -> (25, 135)
seat-11 -> row=2, col=3 -> (355, 245)

width_preview  = (cols x 110) + 50
height_preview = (rows x 110) + 50

โดยที่
110 = ระยะ pitch ระหว่างเก้าอี้แต่ละตำแหน่ง
50  = padding เผื่อขอบกล่อง

ตัวอย่าง
ถ้า rows = 5 และ cols = 6

width_preview  = (6 x 110) + 50 = 710 พิกเซล
height_preview = (5 x 110) + 50 = 600 พิกเซล

6) ขนาดเก้าอี้และระยะห่างที่ใช้จริง
==================================================
จากไฟล์ Client/src/CSS/Chair.css พบว่ากล่องเก้าอี้ที่แสดงผลจริงมีขนาด

chair width  = 80 พิกเซล
chair height = 100 พิกเซล

ดังนั้นในผังตั้งต้นตอนสร้างห้อง

ระยะศูนย์กลางถึงศูนย์กลางแนวนอน = 110 พิกเซล
ระยะศูนย์กลางถึงศูนย์กลางแนวตั้ง = 110 พิกเซล

ถ้าคิดเป็นช่องว่างจริงระหว่างขอบเก้าอี้

ช่องว่างแนวนอน = 110 - 80 = 30 พิกเซล
ช่องว่างแนวตั้ง = 110 - 100 = 10 พิกเซล

สรุปเชิงวิจัย
ระบบผังตั้งต้นให้ความสำคัญกับความเรียบง่ายและการจัดวางแบบสม่ำเสมอ โดยใช้ pitch เท่ากันทั้งสองแกน แต่เนื่องจากเก้าอี้มีความสูงมากกว่าความกว้าง จึงทำให้ช่องว่างแนวตั้งจริงแคบกว่าแนวนอน

7) การจัดผังอัตโนมัติด้วย Chair Presets
==================================================
หลังจากสร้างห้องแล้ว หน้า ClassroomPage สามารถเรียกใช้ ChairPresets.generatePreset() เพื่อจัดผังใหม่โดยไม่เพิ่มหรือลบจำนวนเก้าอี้

หลักการสำคัญคือ

1. จำนวนเก้าอี้คงเดิม
   chairCount = จำนวน key ใน currentChairPositions

2. ระบบคำนวณพิกัดชุดใหม่จาก preset ที่เลือก

3. ระบบ map พิกัดใหม่กลับไปยัง chairId เดิม

ดังนั้น preset เป็นการ "เปลี่ยนตำแหน่ง" ไม่ใช่ "เปลี่ยนจำนวน"

------------------------------------------
7.1 Rows Layout
------------------------------------------
ค่าคงที่ที่ใช้

CHAIR_WIDTH  = 80
CHAIR_HEIGHT = 100
GAP_X        = 40
GAP_Y        = 40
START_X      = 50
START_Y      = 50

สูตรที่ใช้คำนวณจำนวนคอลัมน์
cols_rows = ceil(sqrt(chairCount x 1.5))

จากนั้นคำนวณ
row = floor(i / cols_rows)
col = i mod cols_rows
x = 50 + col x (80 + 40)
y = 50 + row x (100 + 40)

ดังนั้น
ระยะ pitch แนวนอน = 120 พิกเซล
ระยะ pitch แนวตั้ง = 140 พิกเซล
ช่องว่างจริงแนวนอน = 120 - 80 = 40 พิกเซล
ช่องว่างจริงแนวตั้ง = 140 - 100 = 40 พิกเซล

เหตุผลเชิงระบบ
สูตร cols_rows = ceil(sqrt(N x 1.5)) ทำให้ผังมีลักษณะค่อนข้างกว้างกว่าทรงสี่เหลี่ยมจัตุรัสเล็กน้อย ซึ่งเหมาะกับห้องเรียนที่ต้องการมุมมองจากหน้าห้องไปด้านหลัง

------------------------------------------
7.2 Grid Layout
------------------------------------------
สูตรจำนวนคอลัมน์
cols_grid = ceil(sqrt(chairCount))

สูตรตำแหน่ง
row = floor(i / cols_grid)
col = i mod cols_grid
x = 50 + col x (80 + 40)
y = 50 + row x (100 + 40)

ความหมาย
Grid Layout พยายามทำให้ผังมีลักษณะใกล้เคียงสี่เหลี่ยมจัตุรัสมากที่สุด เหมาะกับกรณีที่ต้องการกระจายเก้าอี้ให้สมดุลทั้งแนวราบและแนวดิ่ง

------------------------------------------
7.3 Groups Layout
------------------------------------------
ระบบกำหนดจำนวนสมาชิกต่อกลุ่มตามจำนวนเก้าอี้ทั้งหมดดังนี้

ถ้า chairCount > 20 ให้ chairsPerGroup = 6
ถ้า chairCount <= 6 ให้ chairsPerGroup = 3
กรณีอื่นให้ chairsPerGroup = 4

ค่าสำคัญ
groupSpacing = 280
groupRadius  = 70
START_X      = 50
START_Y      = 50

จำนวนกลุ่มทั้งหมด
totalGroups = ceil(chairCount / chairsPerGroup)

จำนวนกลุ่มต่อบรรทัด
groupsPerLine = ceil(sqrt(totalGroups))

ตำแหน่งศูนย์กลางของแต่ละกลุ่ม
groupRow = floor(g / groupsPerLine)
groupCol = g mod groupsPerLine
centerX = 50 + 70 + (groupCol x 280)
centerY = 50 + 70 + (groupRow x 280)

กรณีสมาชิกในกลุ่มมี 1 คน
x = centerX
y = centerY

กรณีสมาชิกในกลุ่มมี 2 คน
x1 = centerX - 40, y1 = centerY
x2 = centerX + 40, y2 = centerY

กรณีสมาชิกในกลุ่มมี 4 คน
ใช้รูปสี่เหลี่ยม
(-40,-40), (40,-40), (-40,40), (40,40) จากจุดศูนย์กลาง

กรณีสมาชิกจำนวนอื่น
ใช้สมการวงกลม
angle = (2pi x c / chairsInThisGroup) - pi/2
x = centerX + cos(angle) x 70
y = centerY + sin(angle) x 70

ข้อดีเชิงวิจัย
วิธีนี้ช่วยให้ระบบรองรับ active learning หรือการเรียนแบบกลุ่มย่อยได้ดี เพราะตำแหน่งเก้าอี้ถูกกระจายรอบศูนย์กลางกลุ่มอย่างชัดเจน

------------------------------------------
7.4 Scattered Layout
------------------------------------------
ผังชนิด scattered ไม่ได้ใช้การสุ่มจริงทั้งหมด แต่ใช้ pseudo-random แบบกำหนดได้ซ้ำ เพื่อให้ UX คงที่ทุกครั้ง

สูตรเบื้องต้น
cols = ceil(sqrt(chairCount))
cellW = 80 + 80 = 160
cellH = 100 + 80 = 180

row = floor(i / cols)
col = i mod cols

entropyX = ((i x 123) mod 50) - 25
entropyY = ((i x 321) mod 50) - 25

x = 50 + (col x 160) + entropyX + 40
y = 50 + (row x 180) + entropyY + 40

ความหมาย
ค่า entropyX และ entropyY ทำให้แต่ละเก้าอี้เยื้องจากตำแหน่งฐานเล็กน้อย แต่ยังคงอยู่ในช่วงที่คาดเดาได้และไม่กระโดดตำแหน่งมากเกินไป

8) สูตรคำนวณระยะห่างระหว่างเก้าอี้
==================================================
โมดูล Client/src/utils/ChairValidation.js มีฟังก์ชันคำนวณระยะห่างระหว่างเก้าอี้ด้วยระยะทางแบบยูคลิด

d = sqrt((x1 - x2)^2 + (y1 - y2)^2)

โดยที่
d  = ระยะห่างระหว่างเก้าอี้ 2 ตัว
x1 = พิกัด x ของเก้าอี้ตัวที่ 1
y1 = พิกัด y ของเก้าอี้ตัวที่ 1
x2 = พิกัด x ของเก้าอี้ตัวที่ 2
y2 = พิกัด y ของเก้าอี้ตัวที่ 2

ใน utility เดียวกัน มีค่าเริ่มต้น
minDistance = 80

ความหมายของ minDistance
ถ้าระยะ d < 80 ระบบจะมองว่าตำแหน่งนั้นใกล้เกินไปหรือมีความเสี่ยงต่อการชนกัน

ข้อเท็จจริงที่ควรเขียนในงานวิจัยให้ตรงกับระบบจริง
ในเวอร์ชันปัจจุบัน ChairPresets.generatePreset() ยังไม่ได้เรียก resolveCollisions() โดยตรง เพราะในโค้ดมีการเว้นหมายเหตุไว้ว่า spacing แบบคงที่เพียงพอสำหรับ preset ส่วนใหญ่แล้ว ดังนั้นการหลีกเลี่ยงการชนกันของ preset ใช้ "การออกแบบช่องว่างคงที่" เป็นหลัก มากกว่าการแก้ชนแบบ iterative ทุกครั้ง

9) การตรวจสอบขอบเขตและการหาตำแหน่งที่ถูกต้อง
==================================================
ใน Client/src/utils/ContainerUtils.js มีเงื่อนไขตรวจสอบว่าเก้าอี้อยู่ภายในกรอบหรือไม่ โดยใช้ค่าคงที่

CHAIR_RADIUS = 30
NAME_HEIGHT  = 20

สูตรตรวจขอบเขต
x >= 30
x <= width - 30
y >= 30
y <= height - 30 - 20

หรือเขียนย่อได้ว่า
30 <= x <= width - 30
30 <= y <= height - 50

ถ้าเก้าอี้อยู่นอกกรอบ ระบบสามารถบังคับกลับเข้ากรอบด้วยการ clamp ดังนี้

x_new = max(30, min(x, width - 30))
y_new = max(30, min(y, height - 50))

นอกจากนี้ ChairValidation.findNearestValidPosition() ยังมีแนวทางค้นหาตำแหน่งใหม่แบบรัศมีขยายออก

1. เริ่มจาก radius = minDistance
2. เพิ่มรัศมีครั้งละ 20
3. ทดสอบทุกมุมครั้งละ 30 องศา
4. ตำแหน่งแรกที่ไม่ชนและไม่ออกนอกกรอบจะถูกเลือก

10) การคำนวณขนาดกรอบผังในหน้า Classroom จริง
==================================================
เมื่อเข้าสู่หน้า ClassroomPage ระบบไม่ได้ใช้ขนาดกรอบแบบคงที่ตลอดเวลา แต่คำนวณจากขอบเขตของเก้าอี้จริงทั้งหมด

กำหนดให้
minX = ค่าพิกัด x ต่ำสุด
maxX = ค่าพิกัด x สูงสุด
minY = ค่าพิกัด y ต่ำสุด
maxY = ค่าพิกัด y สูงสุด

และใช้
chairWidth  = 80
chairHeight = 100
padding     = 100

สูตรที่ใช้คือ

contentWidth  = maxX + chairWidth  - minX
contentHeight = maxY + chairHeight - minY

finalWidth  = contentWidth  + (2 x padding)
finalHeight = contentHeight + (2 x padding)

จากนั้นระบบแปลตำแหน่งเก้าอี้ทั้งหมดด้วย

translateX = -minX + padding
translateY = -minY + padding

ความหมายเชิงระบบ
แนวคิดนี้ทำให้กลุ่มเก้าอี้ทั้งหมดถูกขยับมาอยู่ภายในกล่องแสดงผลอย่างพอดี และเหลือขอบว่างรอบด้าน 100 พิกเซล เพื่อให้ไม่ชิดขอบมากเกินไป

==================================================
11) การลากย้ายเก้าอี้และการคำนวณภายใต้การซูม
==================================================
เก้าอี้แต่ละตัวถูกลากย้ายผ่าน Client/src/components/Chair.jsx โดยรองรับทั้ง mouse และ touch

สูตรหลักระหว่าง drag มีดังนี้

rawX = clientX - parentLeft - offsetX
rawY = clientY - parentTop  - offsetY

เมื่อมีการซูม
newX = rawX / zoomScale
newY = rawY / zoomScale

จากนั้นระบบบีบค่าให้อยู่ในช่วงที่อนุญาต

newX = max(0, min(newX, logicalContainerWidth  - logicalChairWidth))
newY = max(0, min(newY, logicalContainerHeight - logicalChairHeight))

ถ้าอยู่ในมุมมองครูและมีการหมุนผัง 180 องศา ระบบจะใช้สูตรแก้แกนกลับด้าน

newX = (parentWidth  / zoomScale) - newX - (chairWidth  / zoomScale)
newY = (parentHeight / zoomScale) - newY - (chairHeight / zoomScale)

ความหมาย
แม้ผังจะถูกซูมหรือหมุนกลับด้าน ผู้ใช้ยังสามารถลากเก้าอี้ได้ตรงตำแหน่งเชิงตรรกะจริง ไม่เบี้ยวตามการแสดงผล

15) ตัวอย่างโค้ดที่ใช้อ้างอิงในงานวิจัย
==================================================
ตัวอย่างที่ 1: สร้างตำแหน่งเก้าอี้ตั้งต้นจาก rows และ cols

```javascript
function initializeGridSeating(rows, cols) {
  const positions = {};
  const CHAIR_SPACING = 110;
  const START_OFFSET = 25;

  let seatIndex = 0;
  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      positions[`seat-${seatIndex}`] = {
        x: START_OFFSET + (c * CHAIR_SPACING),
        y: START_OFFSET + (r * CHAIR_SPACING)
      };
      seatIndex++;
    }
  }
  return positions;
}
```

ตัวอย่างที่ 2: คำนวณผังแบบ rows layout

```javascript
function calculateRowLayout(chairCount) {
  const positions = {};
  const CHAIR_WIDTH = 80;
  const CHAIR_HEIGHT = 100;
  const GAP_X = 40;
  const GAP_Y = 40;
  const START_X = 50;
  const START_Y = 50;

  const cols = Math.ceil(Math.sqrt(chairCount * 1.5));

  for (let i = 0; i < chairCount; i++) {
    const row = Math.floor(i / cols);
    const col = i % cols;

    positions[`chair-${i + 1}`] = {
      x: START_X + col * (CHAIR_WIDTH + GAP_X),
      y: START_Y + row * (CHAIR_HEIGHT + GAP_Y)
    };
  }

  return positions;
}
```

ตัวอย่างที่ 3: คำนวณระยะห่างระหว่างเก้าอี้ 2 ตัว

```javascript
function calculateDistance(chair1, chair2) {
  return Math.sqrt(
    Math.pow(chair1.x - chair2.x, 2) +
    Math.pow(chair1.y - chair2.y, 2)
  );
}
```

ตัวอย่างที่ 4: จำกัดไม่ให้เก้าอี้หลุดกรอบ

```javascript
function constrainChairToBounds(x, y, width, height) {
  const CHAIR_RADIUS = 30;
  const NAME_HEIGHT = 20;

  return {
    x: Math.max(CHAIR_RADIUS, Math.min(x, width - CHAIR_RADIUS)),
    y: Math.max(CHAIR_RADIUS, Math.min(y, height - CHAIR_RADIUS - NAME_HEIGHT))
  };
}
```

ตัวอย่างที่ 5: บันทึกผังเก้าอี้ไปยังเซิร์ฟเวอร์

```javascript
await axios.put(`/api/classrooms/${classId}/seating`, {
  seatingPositions: currentChairPositions,
  chairGroups: chairGroups
});
```
