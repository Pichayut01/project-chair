# เอกสารอธิบายการทำงานของฟังก์ชันฝั่ง Client (React Components & Logic)

ฝั่ง Client ของระบบเป็นแอปพลิเคชัน React ที่มีการจัดการสถานะและการโต้ตอบแบบ Real-time โดยแบ่งตามส่วนประกอบหลักดังนี้

## 1. App.jsx (ศูนย์กลางการควบคุมและการนำทาง)

- `handleLoginSuccess`: จัดการเมื่อผู้ใช้เข้าสู่ระบบสำเร็จ (ตั้งค่า User และ Token ลงใน LocalStorage)
- `handleSignOut`: จัดการการล็อกเอาต์และล้างข้อมูลเซสชัน
- `updateUserProfile`: อัปเดตข้อมูลโปรไฟล์ผู้ใช้ในสถานะของแอป
- `toggleSidebar`: เปิด-ปิดแถบเมนูด้านข้าง (Sidebar) พร้อมบันทึกสถานะลงใน LocalStorage

## 2. ClassroomPage.jsx (ตรรกะหลักของห้องเรียน)

หน้านี้เป็นส่วนที่ซับซ้อนที่สุดของระบบ มีฟังก์ชันหลักดังนี้:

- `handleRaiseHand`: ส่งสัญญาณเมื่อนักเรียนกดปุ่ม "ยกมือ" (Raise Hand)
- `handleSendEmoji`: ส่ง Emoji แสดงอารมณ์ไปยังหน้าจอของทุกคน
- `handleAddEvent`: สร้างกิจกรรมใหม่ในห้องเรียน (เช่น ควิซ หรือ การสุ่มเรียก)
- `handleTriggerEvent`: เริ่มต้นกิจกรรมที่สร้างไว้ (เฉพาะครู)
- `handleSubmitAnswer`: นักเรียนส่งคำตอบสำหรับกิจกรรมที่มีคำถาม
- `handleEndAndScoreEvent`: จบกิจกรรมและคำนวณคะแนนให้ผู้เข้าร่วม
- `handleCreateGroups`: ระบบสุ่มแบ่งกลุ่มนักเรียน (Random Grouping)
- `handleChairClick`: จัดการเมื่อมีการคลิกที่เก้าอี้ (เช่น นั่ง, ย้ายที่ หรือจัดการนักเรียน)
- `handleCheckAttendance`: ระบบเช็คชื่อนักเรียนเข้าเรียนในผังที่นั่ง
- `handleApplyRating`: ให้คะแนนเพิ่ม/ลดแก่นักเรียน (Point System)
- `onPromoteMember` / `onDemoteMember`: เปลี่ยนสิทธิ์ของสมาชิกในห้องเรียน

## 3. ส่วนประกอบที่สำคัญ (Key Components)

- `Chair.jsx`: คอมโพเนนต์แสดงผลเก้าอี้แต่ละตัว รองรับการลากวาง (Drag & Drop) และแสดงสถานะต่างๆ (มีคนนั่ง, ว่าง, ยกมือ)
- `ClassroomEvent.jsx`: ส่วนจัดการและแสดงผลกิจกรรมต่างๆ ในระหว่างคาบเรียน
- `ClassChat.jsx`: ระบบแชทแบบ Real-time ภายในห้องเรียน
- `ActionBar.jsx`: แถบเครื่องมือสำหรับครูผู้สอนในการควบคุมห้องเรียน (เช่น สุ่มกลุ่ม, เช็คชื่อ, จัดการกิจกรรม)
- `Navbar.jsx`: แถบนำทางการแจ้งเตือนและเมนูส่วนตัว

## 4. Hooks & Utilities

- `useSocket`: จัดการการเชื่อมต่อ Socket.io และการรับ-ส่ง Event
- `axiosConfig`: ตั้งค่าพื้นฐานสำหรับการเรียกใช้ API (BASE_URL, Auth Headers)
- `formatDate`: ฟังก์ชันจัดรูปแบบวันที่และเวลาสำหรับการแสดงผล
